## 🛠 Part 1: 数据预处理与特征工程 (`data_preprocessing_v2.py`)

我们没有仅仅做“清洗”，而是重构了数据结构，并引入了四个核心的高级特征。

### 1. 数据重构 (Wide to Long Transformation)

原始数据是“宽表”（每位选手一行，Week1-10的数据横向排列），这非常不利于时序分析。

* **操作**：我们将数据转换为“长表”（Long Format），即每一行代表一个“选手-周次”的快照。
* **意义**：使我们能够使用时间序列方法追踪选手的动态变化，并兼容 Plotly/Seaborn 等高级绘图库。

### 2. 深度清洗 (Robust Cleaning)

* **文本解析**：编写了正则解析器处理 `results` 列（如 "Eliminated Week 3", "Runner-up"），精确提取每位选手的生存周期。
* **动态评委处理**：自动识别每赛季/每周的评委人数（3人或4人），避免了硬编码导致的计算错误。

### 3. 核心特征工程 (Feature Engineering) ✨ *创新点*

为了让模型更具解释性，我们构建了以下新指标：

| 特征变量名 | 含义 | 建模用途 |
| --- | --- | --- |
| **`score_ratio`** | **标准化得分 (0-1)** | 消除不同赛季评委人数不同（30分制 vs 40分制）造成的不可比性。 |
| **`judge_controversy`** | **争议指数 (Std Dev)** | 计算单周内4位评委分数的标准差。**高分歧=高争议**，这是题目中分析“偏差”的关键切入点。 |
| **`performance_z_score`** | **统治力 Z-Score** | 。计算选手分数相对于**当周所有选手平均水平**的标准分。这消除了“分数通胀”影响，直接衡量选手的统治地位。 |
| **`momentum`** | **动量 (Momentum)** | 本周表现与上周表现的差值。用于捕捉选手的“进步速度”或“崩溃前兆”。 |

## 📊 Part 2: 叙事性可视化 (`visualization.py`)

为了满足 O 奖对“可视化美学”的要求，我放弃了 Excel 风格，采用 Python `Seaborn` + `Matplotlib` 定制了顶级期刊风格（Nature Style Palette + Times New Roman 字体）。

生成的 4 张 PDF 矢量图不仅是图表，更是我们论文中的四个核心论点：

### 1. 📈 冠军之路 (`Fig1_Champion_Trajectory.pdf`)

* **内容**：展示冠军（Winner）、决赛选手（Finalist）与淘汰者在 `Z-Score` 上的 11 周走势。
* **数学洞察**：**“马太效应”**。图表证明冠军往往在 Week 1 就表现出统计学显著的优势（Z-Score > 1），反驳了“逆袭”假说。这为我们的权重模型提供了依据。

### 2. 🔥 争议热力图 (`Fig2_Controversy_Heatmap.pdf`)

* **内容**：X轴为周次，Y轴为赛季，颜色深浅代表 `judge_controversy`（评委分歧度）。
* **数学洞察**：**“识别异常点”**。颜色最深的区域（深红色）就是评委意见极其不统一的时刻。这些点就是我们在论文中需要重点讨论的“模型失效”或“偏差案例”。

### 3. 🎻 竞争收敛图 (`Fig3_Score_Distribution.pdf`)

* **内容**：小提琴图（Violin Plot）展示每一周分数的分布形状。
* **数学洞察**：**“熵减过程”**。随着周次推移，分数分布从“宽而扁”（水平参差不齐）变为“窄而高”（顶尖对决）。这证明了比赛筛选机制的有效性。

### 4. ⚠️ 淘汰危险区 (`Fig4_Danger_Zone_Scatter.pdf`)

* **内容**：X轴为表现（Z-Score），Y轴为动量（Momentum）。
* **数学洞察**：**“分类边界”**。
* **左下角（红色区域）**：低分且退步，高概率淘汰。
* **右上角（蓝色区域）**：高分且进步，安全。
* **异常值**：**那些落在蓝色区域却被淘汰的点**，就是我们要找的“冤案”（如粉丝投票过低导致的意外淘汰）。

## 🚀 如何运行

1. **准备数据**：确保 `2026_MCM_Problem_C_Data.csv` 在目录下。
2. **生成数据**：运行预处理脚本。
```bash
python data_preprocessing_v2.py

```


*(输出：`processed_data_long.csv`)*
3. **生成图表**：运行可视化脚本。
```bash
python visualization.py

```


*(输出：4个高清 PDF 文件)*
