# 2026 MCM Problem C - Q3: 特征增强与反馈循环优化模型

## 📌 项目概述 (Overview)

在第一问（Q1）中，我们建立了一个基础模型，但在初始状态下，我们对粉丝偏好一无所知，只能假设粉丝投票是均匀分布或随机的。
**Q3 的核心思路是：** 利用机器学习从 Q1 的初步推断结果中学习规律（例如：是不是运动员更受欢迎？年龄是否有影响？），然后将这些规律作为**先验知识 (Priors)** 重新喂回 Q1 的模型中，通过多次迭代，使估计的粉丝票数既符合淘汰事实，又符合选手的个人特征。

### 核心创新点 (Key Innovations)

1. **内生性反馈循环 (Endogenous Feedback Loop)**：
* **Step A (学习)**：训练随机森林模型，学习 `年龄`、`行业`、`搭档` 与 `粉丝票数` 之间的潜在联系。
* **Step B (预测)**：预测每位选手的“理论人气分”。
* **Step C (修正)**：将理论分作为约束条件，重新运行逆向优化，寻找平衡点。


2. **贝叶斯思想的应用**：将 Q3 的预测结果作为 （先验），Q1 的约束作为可能性，最终输出更接近真实的后验分布。
3. **模型收敛验证**：通过计算相邻两次迭代之间的均方根误差 (RMSE)，证明模型经过 3 轮迭代后趋于稳定。

## 📂 生成文件定义 (Output Files)

### 1. `feedback_loop_iter_3.csv` (最终精细化结果)

经过 3 轮迭代后的最终数据。相比 Q1 的结果，这个版本更具“解释性”。

* **新特征：** 包含了 `prior_fan_share`（模型认为根据其背景应得的分数）和 `estimated_fan_share`（结合规则修正后的最终分数）。

### 2. `Model_Comparison_Metrics.csv` (模型对比指标)

由 `对比.py` 生成，用于定量说明 Q3 比 Q1 进步了多少：

* **Entropy (信息熵)**：熵的降低说明模型对粉丝分布的判断不再“混乱”，而是更有针对性。
* **Concentration (集中度)**：验证了“马太效应”，即少数头部选手占据大量选票的现实情况。

## 📊 图表解读与论文素材 (Visualization Guide)

### 🖼️ `Loop_Convergence.pdf` (收敛曲线图)

* **内容**：横轴是迭代次数，纵轴是 RMSE。
* **解读**：曲线应呈下降趋势并趋于平缓。
* **论文写作点**：证明我们的模型具有**稳定性**。迭代 3 次后，模型不再大幅修正，说明已找到特征与规则之间的最优解。

### 🖼️ `Loop_Prior_vs_Posterior.pdf` (理论 vs 现实)

* **内容**：横轴是 Q3 模型预测的理论分，纵轴是 Q1 约束修正后的最终分。
* **解读**：
* **回归线附近的点**：代表选手的表现完全符合其身份背景。
* **偏离较大的点**：代表该选手在特定周次内出现了“爆冷”或“超常发挥”。



### 🖼️ `Model_Comparison_Report.pdf` (对比报告)

这是论文中最有力的视觉支撑：

* **Fig 1 (KDE Plot)**：展示从“均匀分布”到“偏态分布”的转变。证明 Q3 成功识别出了明星效应。
* **Fig 2 (Scatter Plot)**：直接标出哪些选手的评分被模型“大幅修正”了。这可以作为论文中的 **Case Study**（个案研究）。
