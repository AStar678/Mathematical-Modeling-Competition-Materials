# 2026 MCM Problem C - Q1: 粉丝投票重构模型 (Fan Vote Reconstruction)

## 📌 项目概述 (Overview)

本项目针对 Problem C 第一问，建立了一个**基于约束的逆向优化模型 (Constraint-Based Inverse Optimization Model)**。
我们的目标不是“预测”谁被淘汰（因为结果已知），而是**推断**出什么样的粉丝投票分布（Fan Votes），才能在数学上解释已知的淘汰结果。

### 核心创新点 (Key Innovations for O-Award)

1. **潜在变量推断 (Latent Variable Inference)**: 将未知的粉丝票数视为待求解变量，而非简单的回归预测。
2. **双重赛制适配 (Dual-System Adaptation)**: 代码自动识别并分别处理 **排名制 (Rank System)** (S1-2, S28+) 和 **百分比制 (Percent System)** (S3-27)。
3. **时序贝叶斯平滑 (Bayesian Time Smoothing)**: 引入先验概率（Prior），假设粉丝群体具有粘性（即上周人气高的人，这周大概率人气依然高），避免数据剧烈抖动。
4. **硬约束与软约束 (Hard & Soft Constraints)**:
* **硬约束**: 淘汰者的综合得分必须低于（或劣于）存活者。
* **软约束**: 粉丝投票应尽量符合历史趋势，且与评委打分存在弱相关性。

## 📂 输出文件说明 (Output Files)

代码运行后会生成两个核心 CSV 文件，直接用于后续分析和论文制表。

### 1. `estimated_fan_votes_final.csv` (核心结果表)

这是最重要的数据文件，包含了每一位选手在每一周的推断数据。

| 列名 (Column) | 含义 (Description) | 论文用途 |
| --- | --- | --- |
| `season` / `week` | 赛季 / 周次 | 时间序列分析 |
| `contestant` | 选手姓名 | 个案研究 |
| `judge_share` | **评委打分占比** (归一化实力) | 代表选手的“技术得分” |
| `estimated_fan_share` | **估计粉丝投票占比** (模型输出) | 代表选手的“人气得分” (Q1的核心答案) |
| `is_eliminated` | 是否当周被淘汰 | 验证模型的Ground Truth |
| `method` | 赛制 (`percent` 或 `rank`) | 说明不同时期的计算规则 |

### 2. `season_accuracy_table.csv` (模型验证表)

用于证明模型有效性的统计表。

| 列名 (Column) | 含义 (Description) | 论文用途 |
| --- | --- | --- |
| `Accuracy` | 模型解释成功率 | 证明模型在S3-S27期间达到**100%准确率**；同时揭示S28之后由于**Judge Save（评委拯救权）**引入导致的准确率下降（这是一个非常好的分析点）。 |

## 📊 图表解读指南 (Visualization Guide)

代码生成的5张图表直接对应论文中的“结果分析”和“模型评估”部分。

### 🖼️ Plot 1: `plot1_correlation.png` (评委 vs 粉丝)

* **内容**: 横轴是评委分占比，纵轴是粉丝票占比。
* **怎么看**:
* **对角线**: 点在对角线附近，说明粉丝和评委意见一致。
* **左上角区域**: **关键区域！** 代表“评委分低、粉丝分高”的选手（如Bobby Bones）。这展示了模型成功捕捉到了**观众宠儿 (Fan Favorites)**。
* **右下角区域**: 代表“评委分高、粉丝分低”的选手，通常是“技术好但没人气”的淘汰高危人群。



### 🖼️ Plot 2: `plot2_trends.png` (人气趋势)

* **内容**: 某赛季（如S23）头部选手的人气随时间变化曲线。
* **怎么看**:
* 曲线应当是平滑的（没有剧烈跳变），这验证了我们模型假设的合理性（粉丝基础是稳定的）。
* 观察是否有**上升趋势**的曲线，这代表了“黑马”选手的成长路径。



### 🖼️ Plot 3: `plot3_accuracy.png` (准确率柱状图)

* **内容**: 每个赛季的模型解释准确率。
* **论文写作点**:
* 指出 **S3-S27** 的完美表现（100%），证明在规则明确时模型极其精准。
* 指出 **S28** 后的波动。**注意：不要说这是模型误差！** 要在论文中解释这反映了赛制规则的改变（评委拥有了最终拯救权），导致单纯的分数逻辑失效。这反而证明了模型能检测出“异常干预”。



### 🖼️ Plot 4: `plot4_margins.png` (安全边际分布)

* **内容**: 直方图。X轴是 `安全分 - 淘汰分`。
* **怎么看**:
* **正值 (右侧)**: 表示淘汰结果毫无悬念，淘汰者得分远低于存活者。
* **0附近 (左侧)**: 表示**险胜**。这是比赛最刺激、最不确定的时刻。
* 此图用于回答题目中关于 **"Certainty" (确定性)** 的问题。



### 🖼️ Plot 5: `plot5_heatmap.png` (分歧热力图)

* **内容**: 评委排名 vs 粉丝排名的混淆矩阵。
* **怎么看**:
* 颜色越深表示该情况发生次数越多。
* 如果深色块集中在对角线，说明一致性高。
* **非对角线的深色块**直观展示了粉丝和评委的分歧程度（Controversy）。
