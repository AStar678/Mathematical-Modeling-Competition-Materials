# 📂 MCM Task 4: 商业价值最大化评价模型 (The "Buzz vs. Risk" Model)

> **目标：** 冲击 O 奖 (Outstanding Winner)
> **核心理念：** 放弃传统的“公平性”追求，转而追求“商业利益最大化”。最佳的评价系统不是选出跳舞最好的人，而是在不导致观众大规模退订的前提下，制造最大的舆论热度。

---

## 1. 核心思路 (The Big Idea)

我们提出了一个 **“舆论-风险博弈模型” (Buzz-Risk Game Model)**。

* **传统的思维误区：** 试图让比赛更公平（例如调整权重让专业分更重要）。
* **我们的创新思维：** * **热度 (Buzz):** 来自争议。淘汰一个受观众喜爱（但可能跳得不好）的选手，会引发社交媒体讨论，提升节目知名度。
* **风险 (Churn Risk):** 只有当“底线”被触碰（例如绝对顶流被黑幕淘汰）时，观众才会愤怒到不再观看。
* **甜蜜点 (The Sweet Spot):** 我们的模型寻找的是那些 **“有人气但不是顶流”** 的选手（人气排名 3-5 名）。淘汰他们能引发“意难平”的讨论（收益），但不足以让观众退订（低风险）。
